⚠ AI 自由生成 · 风险提示

  • 自由生成由 AI 组织表达与语气，事实（学校、专业、技能、月数、天数等）由系统按占位符确定性回填，AI 环节看不到也不会编造具体事实值。
  • 内置规则句与默认句可能包含通用技能描述；若技能句并非来自你的个人资料，话术会提示"请核对"，请确认自己确实具备后再投递。
  • 但连接词与语气仍由模型生成，兜底校验可降低、无法 100% 杜绝异常表达；生成结果请人工确认后再投递。
  • 此模式需把生成模式设为 AI / HYBRID；RULE 模式下会自动回退到内置模板。
  • 每次生成按实际 token 用量计费；平台额度用尽时自动回退内置模板，也可接入自带 API Key。
